# Tiny Earth Humanity Simulator

작은 동그란 3D 지구 위에서 한 인류 문명을 운영하는 브라우저 시뮬레이터입니다.

## Features

- Three.js 기반 3D 미니 행성
- 인구, 식량, 광석, 부품, 전력, 건강, 생태, 통합 시뮬레이션
- 건설, 연구, 정책, 랜덤 사건, 승리/패배 엔딩
- 자동 운영관 AI 모드
- 데스크톱/모바일 반응형 HUD

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
